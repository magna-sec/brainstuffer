♘ Tactic Cycles

One fixed set of puzzles, solved over and over against a halving clock. Not a puzzle feed — the whole point is meeting the same positions until recognising them stops being calculation and becomes memory.

Build your set

Pick your chapters. The set is frozen once you start — cycle times mean nothing if the set changes underneath them.

Use your own puzzles instead

Paste a PGN whose games carry a [FEN] tag (what a lichess study exports), or one puzzle per line as FEN | moves. Moves can be SAN or UCI. In an imported puzzle you move first, as positions are posed in books and studies.

Imported sets are saved in this browser only. Nothing is uploaded and nothing is added to the site.

How the method works
  1. Solve the whole set once. Budget about four weeks.
  2. Rest a day or two.
  3. Solve the same set again, in half the days.
  4. Keep halving: 28 → 14 → 7 → 4 → 2 → 1.
  5. Stop when you clear the set in a single day, or after cycle 7.

This is deliberately not spaced repetition. There are no per-puzzle intervals — only whole-set cycles against a shrinking clock.
